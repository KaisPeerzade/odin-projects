# Restaurant Page

A simple restaurant website built as part of [The Odin Project](https://www.theodinproject.com/) curriculum.

This project was created to practice **JavaScript modules, DOM manipulation, npm, and Webpack**.

## Features

* Home tab
* Menu tab
* Contact tab
* Tab switching without reloading the page
* Page content generated using JavaScript
* CSS styling
* Webpack development setup

## Built With

* HTML
* CSS
* JavaScript
* npm
* Webpack

## How to Run

Clone the repository and enter the project folder:

```bash
git clone <your-repository-link>
cd Restaurant-Page
```

Install the dependencies:

```bash
npm install
```

Start the Webpack development server:

```bash
npm start
```

Then open:

```text
http://localhost:8080
```
